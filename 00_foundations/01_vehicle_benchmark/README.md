# Vehicle Benchmark: Reference Vehicle & Tire Specification

## Purpose
This folder establishes a single, consistent reference vehicle and tire
parameter set that will be reused across the portfolio (tire model, suspension, 
brakes, aerodynamics, lap-time simulation, optimization, digital twin).

## Vehicle Class
Generic open-wheel, formula-style race car (Formula SAE-scale), chosen because:
- It aligns with the aerodynamic case studies (rear wing, ground-effect diffuser).
- It aligns with the exposed double-wishbone suspension case study.
- It keeps early physics simpler while model fidelity is still being built up.
- All parameters are kept editable/parametric, so the vehicle can later be
  scaled toward higher-downforce, higher-mass classes (like GT-style) as
  a variant study.
